about=Processing tools for wildfire burn severity, modeled on the MTBS QGIS Fire Mapping Tool. They appear in the Processing Toolbox under Wildfire Analysis Toolkit.
    
    Burn severity (whole pipeline) goes from a fire's perimeter and dates to an image pair, pre- and post-fire NBR, dNBR with the unburned offset, MTBS severity classes, area summaries per sub-area and an HTML report. The fire name and dates can be read from a WFIGS perimeter record. Severity map (PDF) makes a print-ready map.
    
    Imagery: NASA HLS v2.0 (needs a free NASA Earthdata login in a .netrc file), Landsat 4-9 Collection 2 and Sentinel-2 L2A from Microsoft Planetary Computer (no account), or scenes you downloaded. Images are calibrated from their metadata, cloud-masked, and read only for the area of interest.
    
    Severity: Build dNBR (dNBR, RdNBR, RBR and the offset), Draft burned-area perimeter, Classify severity (MTBS classes, with thresholds given or estimated from nearby MTBS fires), and Burn severity summary (percent, hectares and acres per class for a fire and its sub-areas).
    
    Validated against published MTBS fires: with MTBS's thresholds, the classes agree at a mean kappa of 0.78. Uses only QGIS, GDAL and NumPy, which ship with QGIS.
    
    The README in the code repository has every parameter, the method, troubleshooting and the validation results.
